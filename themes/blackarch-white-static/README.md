# BlackArch White Static Plymouth theme

Uses the supplied static white BlackArch artwork with a matching glowing loading
bar. Select `blackarch-white-static` in PoeDeploy's Plymouth theme menu.

Installable archive: [`plymouth/blackarch-white-static.zip`](plymouth/blackarch-white-static.zip).

![BlackArch White Static layout preview](preview.png)

See the [theme documentation](../README.md) for sizing, rebuilding, behaviour,
and artwork provenance. `logo.png` is the unmodified user-supplied source.
