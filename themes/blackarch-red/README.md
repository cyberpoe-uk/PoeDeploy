# BlackArch Red Plymouth theme

Uses the supplied 24-frame red BlackArch animation at 18 fps with a matching
glowing loading bar.
Select `blackarch-red` in PoeDeploy's Plymouth theme menu.

Installable archive: [`plymouth/blackarch-red.zip`](plymouth/blackarch-red.zip).

![BlackArch Red layout preview](preview.png)

See the [theme documentation](../README.md) for sizing, rebuilding, behaviour,
and artwork provenance. The animation frames are packaged inside the archive.
