# BlackArch Green Static Plymouth theme

Uses the original static green BlackArch artwork with a matching glowing loading
bar. Select `blackarch-green-static` in PoeDeploy's Plymouth theme menu.

Installable archive: [`plymouth/blackarch-green-static.zip`](plymouth/blackarch-green-static.zip).

![BlackArch Green Static layout preview](preview.png)

See the [theme documentation](../README.md) for sizing, rebuilding, behaviour,
and artwork provenance. `logo.png` is the unmodified user-supplied source.
