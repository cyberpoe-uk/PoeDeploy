# BlackArch Orange Static Plymouth theme

Uses the original static orange BlackArch artwork with a matching glowing loading
bar. Select `blackarch-orange-static` in PoeDeploy's Plymouth theme menu.

Installable archive: [`plymouth/blackarch-orange-static.zip`](plymouth/blackarch-orange-static.zip).

![BlackArch Orange Static layout preview](preview.png)

See the [theme documentation](../README.md) for sizing, rebuilding, behaviour,
and artwork provenance. `logo.png` is the unmodified user-supplied source.
