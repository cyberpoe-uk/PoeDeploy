# PoeDeploy Plymouth themes

Repository-managed themes use this layout:

```text
themes/<theme-name>/plymouth/<theme-name>.zip
```

PoeDeploy discovers archives matching that layout automatically. A theme archive must contain its `.plymouth` file and all referenced assets.

The BlackArch themes use the four supplied transparent logos, a black background,
and a 460×6 px progress bar with two layers of soft outer glow and a fine highlight.
Visible artwork is fitted within 480×354 px without changing its aspect ratio,
so it overhangs the bar by at most 10 px on each side. A 26 px gap separates the
bottom of the artwork from the bar. The combined 528×460 px frame is centred and
fits a 640×480 display at scale 1. Plymouth applies its normal HiDPI scaling.

Each archive uses the same two-step renderer and password/keyboard resources as
PoeDeploy. There are 51 boot-progress frames and a single completed end frame.
the full bar remains visible until Plymouth exits. Native update/upgrade bars
also match the theme colour. Their native renderer does not draw the custom glow.

Run PoeDeploy from this checkout, select the Plymouth setup module, and choose
`blackarch-green`, `blackarch-orange`, `blackarch-purple`, or `blackarch-red`.
Local archives are discovered without needing to publish them to GitHub.

To rebuild all four archives and their deterministic 50% layout previews:

```bash
# Requires ImageMagick 7, unzip and Python 3.
bash themes/build-blackarch.sh
```

`logo.png` in each directory is the unmodified supplied source. The builder only
crops transparent margins and scales the logo when composing the UI frames.
It uses the existing PoeDeploy archive as the template for theme settings and
prompt resources. ZIP entries have stable ordering, permissions and timestamps.

`screenshot.png` files are actual 1920×1080 captures of the themes running in
Plymouth's X11 renderer, with normal boot progress. They were captured in an
isolated Bubblewrap session with a private `/run` and read-only system mounts.
the host's boot theme and initramfs were not changed. `preview.png` files are
rendered layouts at exactly 50% progress, regenerated by the builder.

Artwork provenance: the BlackArch logos were supplied by the repository owner
for this addition. No external theme archive was imported. The source artist,
original source URL and artwork licence were not supplied. No additional licence
is asserted for those logos. Existing PoeDeploy prompt resources are retained
from this repository.

Themes created for PoeDeploy belong under `themes/`. PoeDeploy does not download third-party theme collections during installation. Curated third-party themes must be reviewed and added to this repository individually.

Do not add a third-party archive without also including its licence, source URL, author attribution, and any notices required by its licence.
