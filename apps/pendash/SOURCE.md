# PenDash embedded source

This directory was imported from PenDash commit
`6601a22ac4dd864be0c5d8df1b9ad3e5ce5c16ad` and is now maintained as part of
PoeDeploy. It contains the dashboard installer, runtime assets, Chromium/Burp
integration, and focused tests. The original hardware-specific laptop
installation workflow has been removed.
